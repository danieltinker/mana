# Mana: the published site

This branch is exactly what halom.io serves under `/mana/` and `/m/<name>`, through GitHub Pages
(`https://danieltinker.github.io/mana/`). The source is on `main`. Publish with `bash tools/publish.sh` from `main`;
do not edit the built files here by hand. `config.js` is the one file that lives only here.

Copied on 12 Oct 2026 from `danieltinker/halom-projects`, folder `projects/menus/`, at commit aab11f3. Its earlier
history is in that repository. One change on the way: under `/m/<name>` the guest menu's base is `/mana/view/`
(it was `/projects/menus/view/`).
